Criterios Técnicos de Desarrollo

1. Solo Transform y Opacity

Animar propiedades como top, left o margin obliga al navegador a recalcular el layout completo en cada frame. Solo se animan transformaciones de composición.

2. Gestión de VRAM

Declarar will-change: transform en CSS de forma permanente satura la memoria gráfica de los móviles. Se activa en JavaScript al iniciar y se limpia en onComplete.

3. Cero consumo en background

Ninguna animación en bucle sigue corriendo cuando el usuario hace scroll hacia otra sección. Se pausan con IntersectionObserver.

4. Accesibilidad (a11y)

Detección automática de prefers-reduced-motion para respetar la configuración de usuarios sensibles al movimiento.
