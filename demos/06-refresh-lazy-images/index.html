El error silencioso de combinar loading="lazy" con ScrollTrigger. Solución en dos capas: reserva dimensional en CSS y recálculo reactivo con ScrollTrigger.refresh().

1. El Problema del Descalibre

Cuando una imagen sin tamaño fijo carga en segundo plano, empuja el DOM hacia abajo. ScrollTrigger ya calculó sus coordenadas de disparo y queda apuntando al vacío.

ASSET 02 · 16:9 RESERVED

2. Primera Capa: Prevención en CSS

Declarar aspect-ratio: 16/9 reserva el espacio antes de que el primer byte viaje por la red, garantizando un Cumulative Layout Shift (CLS) exacto de 0.

ASSET 03 · 16:9 RESERVED

3. Segunda Capa: Red de Seguridad JS

Para imágenes dinámicas con proporciones variables, nos suscribimos al evento load con { once: true } para invocar ScrollTrigger.refresh() automáticamente.
