Técnica: Zero CLS & Recalibración ScrollTrigger

Recálculo tras Imágenes Diferidas

El error silencioso de combinar loading="lazy" o acordeones con ScrollTrigger: cuando el elemento termina de cargar o se expande, empuja el DOM hacia abajo y descalibra los triggers. La solución es reservar el espacio en CSS con aspect-ratio y ejecutar ScrollTrigger.refresh() de forma reactiva.

Puntuación CLS 0.000 (Sin saltos)
Reserva Dimensional aspect-ratio: 16 / 9
Estado ScrollTrigger Calibrado (0px error)

Este bloque empuja físicamente el contenido inferior en 150px. Al abrirlo o cerrarlo, disparamos ScrollTrigger.refresh() automáticamente para que las tarjetas de abajo se sincronicen al instante.

✓ ScrollTrigger.refresh() invocado en el evento de transición
EJEMPLO 01 · 16:9 RESERVED

1. Prevención en CSS con aspect-ratio

Al definir aspect-ratio: 16/9 en el contenedor de la imagen, el navegador reserva la altura exacta desde el primer momento, logrando un CLS de 0 antes de que descargue la imagen.

2. Red de Seguridad con Event Listener

Para imágenes dinámicas subidas por el cliente sin proporción fija en WordPress, escuchamos el evento load con { once: true } para recalibrar ScrollTrigger cuando aterriza el archivo.
