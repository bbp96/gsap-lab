La explicación del Pipeline de Renderizado del Navegador

El motor de renderizado ejecuta tres pasos principales: Layout → Paint → Composite.

Cuando animas top o left, el navegador debe recalcular la geometría de toda la página (Layout) y volver a rasterizar los píxeles (Paint) 60 veces por segundo en el hilo principal de JavaScript. Esto satura la CPU y causa tirones (Jank).

Cuando animas transform: translate3d(...), el navegador salta directamente a la fase de Composite. La capa se envía a la memoria de la GPU, dejando el hilo principal completamente libre a 60 FPS con 0 ms de bloqueo (TBT 0ms).
