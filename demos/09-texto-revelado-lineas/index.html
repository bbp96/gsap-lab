Técnica: Máscaras CSS + Desglose Nativo en Vanilla JS

Texto Revelado por Líneas sin Plugins de Pago

El plugin SplitText de GSAP pertenece a la membresía de pago de Club GreenSock. Esta demo demuestra cómo lograr el mismo efecto de revelado tipográfico editorial de alta gama usando envoltorios con overflow: hidden en puro JavaScript Vanilla, sin dependencias externas ni impacto en el bundle.

Construyendo experiencias web que cargan en milisegundos.

La tipografía animada debe preservar la accesibilidad semántica del DOM. Dividir los nodos en capas compuestas por GPU permite transiciones fluidas a 60 FPS sin alterar los lectores de pantalla.

Cómo funciona el desglose nativo seguro

El script toma el texto original y envuelve cada segmento en una estructura de dos niveles: <span class="reveal-mask"><span class="reveal-inner">Texto</span></span>.

La etiqueta exterior actúa como máscara recortadora (overflow: hidden) y la interior se desplaza en el eje Y mediante yPercent: 110 hacia yPercent: 0 con stagger y una curva power4.out. Esto no provoca recálculos de layout (Reflow) porque solo se modifica la matriz de transformación en GPU.
