Técnica: gsap.quickTo() · Tubería Directa sin Asignación en Heap

Cursor Magnético & Físicas Inerciales con quickTo()

Animar cursores o botones en cada evento mousemove con gsap.to() crea cientos de objetos por segundo y satura el Garbage Collector. gsap.quickTo() canaliza los datos directamente al motor de render sin asignar memoria nueva.

Nuevos Tweens en Heap 0 / seg Instancias recicladas con quickTo
Estado del Dispositivo Puntero Físico Desactivado en pantallas táctiles
Pipeline FPS 60 FPS Sin pausas de Garbage Collector

Física Inercial de Dos Capas

El punto central reacciona al instante (duration: 0.08s), mientras que el anillo exterior tiene inercia y amortiguación elástica (duration: 0.38s con power3.out). Mueve el ratón rápidamente para ver el desfase elástico.

Atracción Magnética Progresiva

Acerca el ratón a los botones: al entrar en su radio de influencia, son atraídos hacia el cursor con cálculo trigonométrico relativo y vuelven suavemente a su centro al salir.

Arquitectura de Software y WPO de Alto Rendimiento

Pasa el cursor sobre el texto: el anillo se expande dinámicamente y activa mix-blend-mode: difference, invirtiendo los colores del fondo y los caracteres con total nitidez.

Por qué gsap.quickTo() supera a gsap.to() en eventos continuos

En la Web moderna, eventos como pointermove, scroll o wheel pueden dispararse cientos de veces por segundo. Usar gsap.to() en estos eventos es una de las causas principales de pérdida de cuadros (*frame drops*).

✕ Patrón Ineficiente (gsap.to) Heap Churn 
// Crea ~200 tweens nuevos por segundo
window.addEventListener('pointermove', (e) => {
  gsap.to(cursor, {
    x: e.clientX,
    y: e.clientY,
    duration: 0.3,
    overwrite: 'auto' // Sobrecarga de cálculo
  });
});
✓ Patrón Optimizado (gsap.quickTo) Zero GC Spikes 
// Pre-instancia la tubería una sola vez
const setX = gsap.quickTo(cursor, 'x', { duration: 0.3, ease: 'power3.out' });
const setY = gsap.quickTo(cursor, 'y', { duration: 0.3, ease: 'power3.out' });

// En el listener solo actualiza los valores numéricos
window.addEventListener('pointermove', (e) => {
  setX(e.clientX);
  setY(e.clientY);
});

Al desacoplar la creación de la animación de su actualización numérica, el navegador mantiene el hilo principal despejado, garantizando un presupuesto de frame inferior a 16.6 ms.
