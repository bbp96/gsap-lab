Linear Scrub & Timeline Sync

Parallax con Velocidades Diferenciadas

Profundidad óptica real calculada mediante una única Timeline sincronizada con el scroll del usuario. Easing estrictamente lineal (`none`) y desacoplamiento del hilo principal.

// LAYER 02 · MID

Velocidad media (-320px). Proporciona el plano de referencia intermedio.

ARQUITECTURA DE PROFUNDIDAD

La velocidad define la distancia

En el mundo físico, los objetos lejanos aparentan quietud mientras los cercanos cruzan el campo visual a alta velocidad. Replicar este gradiente de deltas de movimiento genera profundidad espacial inmersiva.

// LAYER 03 · FAST

Desplazamiento Rápido (-540px)

Scroll Progress 0.0%
Fondo (Layer 1) 0 px
Medio (Layer 2) 0 px
Frente (Layer 3) 0 px
Scrub Damping 1.5s (Smooth)
Por qué una sola Timeline y no múltiples listeners: Crear un ScrollTrigger independiente por cada capa multiplicaría innecesariamente los callbacks por frame de scroll. Con una sola Timeline sincronizada (timeline.to(layer, { y: speed }, 0)), GSAP evalúa todo el conjunto en un solo cálculo de punto flotante por frame. Además, el parámetro ease: 'none' es obligatorio: en efectos dirigidos por scroll, el easing lo dicta la mano del usuario, no un temporizador de reloj.
